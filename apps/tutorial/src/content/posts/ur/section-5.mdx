سیکشن 5 میں خوش آمدید! اب تک ہم static اور dynamic HTML مواد کی اسکریپنگ، متعدد صفحات والی سائٹس میں نیویگیشن، اور APIs اور forms کے ساتھ تعامل کا احاطہ کر چکے ہیں۔ اب ہم متن سے آگے بڑھتے ہوئے میڈیا مواد کے استخراج کا جائزہ لیں گے۔ اس سیکشن میں ویب اسکریپنگ کے دوران سامنے آنے والی مختلف media اقسام کو سنبھالنے کی تکنیکوں پر توجہ دی گئی ہے۔

### 1. تصاویر اور metadata نکالنا (باب 10)

تصاویر ویب مواد کا ایک اہم حصہ ہوتی ہیں، اور ان کی اسکریپنگ صرف فائلیں ڈاؤن لوڈ کرنے تک محدود نہیں ہوتی۔ اکثر قیمتی سیاقی معلومات متعلقہ metadata میں محفوظ ہوتی ہیں۔

**اہم تصورات:**

* **تصویر کی شناخت:** HTML میں image elements تلاش کرنے کے لیے selectors استعمال کرنا (`<img>` tags، background images، وغیرہ)
* **metadata کا استخراج:** اہم معلومات جمع کرنا، جیسے:
  * `alt` متن (رسائی پذیری کے لیے نہایت اہم اور تصویر کے مواد کی وضاحت کے لیے مفید)
  * filenames (اکثر تاریخوں یا موضوعات جیسی وضاحتی معلومات پر مشتمل ہوتے ہیں)
  * captions اور اردگرد کا متن
  * حسبِ ضرورت data attributes (مثلاً `data-photographer`، `data-location`)
* **تصویر ڈاؤن لوڈ کرنا:** تصاویر کو مؤثر انداز میں محفوظ کرنے کی تکنیکیں، جبکہ تنظیم برقرار رکھی جائے
* **EXIF Data:** بعض تصاویر کے لیے embedded فنی metadata نکالنا (camera settings، GPS coordinates، وغیرہ)

**چیلنج (باب 10):** آپ ایک digital archive ویب سائٹ کی اسکریپنگ کریں گے جس میں مختلف تاریخی تصاویر موجود ہیں۔ آپ کا کام صرف خود تصاویر نکالنا نہیں بلکہ ان سے متعلق تمام metadata بھی حاصل کرنا ہے، جس میں alt متن، filename کی معلومات، captions، اور custom attributes شامل ہیں۔

### 2. PDFs ڈاؤن لوڈ اور parse کرنا

ویب پر بہت سے قیمتی دستاویزات PDFs کی صورت میں محفوظ ہوتے ہیں، اور ان کے مواد کے استخراج کے لیے خاص طریقۂ کار درکار ہوتا ہے۔

**اہم تصورات:**

* **PDF کی شناخت:** ویب صفحات پر PDF links تلاش کرنا
* **ڈاؤن لوڈ کرنا:** PDF files حاصل کرنے کی تکنیکیں
* **متن کا استخراج:** متن نکالنے کے لیے `pdf-parse` یا `pdf.js` جیسی libraries استعمال کرنا
* **ساختہ بند data:** ایسے دستاویزات کو سنبھالنا جن میں یہ شامل ہو:
  * بنیادی متن
  * tables اور columns
  * forms
  * embedded تصاویر
* **metadata تک رسائی:** دستاویز کی خصوصیات نکالنا (title، author، creation date)

**چیلنج (باب 10):** digital archive اسکریپنگ مشق کے حصے کے طور پر، آپ مختلف ساختوں والے PDF دستاویزات ڈاؤن لوڈ کریں گے—سادہ text-based دستاویزات سے لے کر زیادہ پیچیدہ دستاویزات تک جن میں tables اور embedded تصاویر شامل ہوں۔ آپ کے حل کو اس مواد کو مناسب انداز میں نکالنا اور منظم کرنا ہوگا۔

### 3. Embedded ویڈیو metadata کی اسکریپنگ

ویڈیوز عموماً ویب صفحات میں iframes یا مخصوص players کے ذریعے embed کی جاتی ہیں، اور ان کا metadata مختلف تکنیکوں کے ذریعے حاصل کیا جا سکتا ہے۔

**اہم تصورات:**

* **ویڈیو embed کی شناخت:** embed کرنے کے مختلف طریقوں کو پہچاننا:
  * YouTube/Vimeo iframes
  * HTML5 `<video>` elements
  * custom video players
* **metadata کا استخراج:** یہ معلومات جمع کرنا:
  * ویڈیو titles اور descriptions
  * platform کی معلومات
  * video IDs یا direct URLs
  * duration، uploader، اور دیگر دستیاب attributes
* **thumbnail تک رسائی:** ویڈیوز سے متعلق preview تصاویر حاصل کرنا

**چیلنج (باب 10):** digital archive مشق کے آخری حصے میں آپ کو متعدد ذرائع سے embedded ویڈیوز کے بارے میں معلومات نکالنی ہوں گی، جن میں YouTube، Vimeo، اور native HTML5 video elements شامل ہیں۔

### OSINT & Digital Forensics کی عملی کاربردیں

اس سیکشن میں شامل تکنیکوں کے Open Source Intelligence (OSINT) اور digital forensics میں بھی استعمالات ہیں۔ میڈیا metadata مواد کی authenticity سے متعلق اہم معلومات ظاہر کر سکتا ہے، جن میں publication dates میں تضاد، جغرافیائی اصل، اور source معلومات شامل ہیں۔

یہ مہارتیں اُن researchers اور analysts کے لیے نہایت مفید ہیں جو ایسے شعبوں میں کام کرتے ہیں جہاں مواد کی verification بہت اہم ہوتی ہے۔ اگر آپ ان استعمالات کے بارے میں مزید سیکھنے میں دلچسپی رکھتے ہیں تو [OSINT Framework](https://osintframework.com/) یا [Intel Techniques](https://inteltechniques.com/index.html) جیسے وسائل دیکھیں۔

اگرچہ ہم اپنی مشقوں میں investigative تکنیکوں پر توجہ نہیں دیں گے، لیکن یہ سمجھنا کہ metadata کو کیسے نکالا اور analyze کیا جا سکتا ہے، جامع ویب اسکریپنگ منصوبوں کے لیے ایک اہم مہارت ہے۔

### عملی پہلو

میڈیا مواد کی اسکریپنگ کرتے وقت ان اہم عوامل کو ذہن میں رکھیں:

1. **Storage کی ضروریات:** media files بڑی ہو سکتی ہیں—اسی حساب سے منصوبہ بندی کریں
2. **Bandwidth کا استعمال:** بڑی تعداد میں media files ڈاؤن لوڈ کرنے سے خاصی bandwidth صرف ہو سکتی ہے
3. **Rate Limiting:** بہت سی سائٹس media downloads کی رفتار محدود کرتی ہیں
4. **قانونی پہلو:** media مواد پر copyright پابندیوں سے باخبر رہیں
5. **Error Handling:** بعض media تک رسائی ممکن نہیں ہو سکتی یا وہ corrupted ہو سکتے ہیں—آپ کے حل کو ایسے معاملات کو مناسب انداز میں سنبھالنا چاہیے

ان تکنیکوں پر عبور حاصل کرنے سے آپ کی ویب اسکریپنگ صلاحیتیں متن پر مبنی مواد سے کہیں آگے بڑھ جائیں گی، اور آپ ویب پر دستیاب media کی مکمل وسعت کو حاصل اور استعمال کر سکیں گے۔

اسکریپنگ مبارک!
