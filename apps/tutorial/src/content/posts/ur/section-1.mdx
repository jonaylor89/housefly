ویب اسکریپنگ شروع میں خوف زدہ کر دینے والی لگ سکتی ہے، لیکن ہر مہارت کی طرح اسے سیکھنے کا بہترین طریقہ عملی مشق ہے۔ ان ابتدائی تین ابواب میں ہم جامد HTML صفحات سے data نکالنے کی بنیادیات کا جائزہ لیں گے۔

## باب 1: HTML Scraper Chad

ہمارا سفر ممکنہ طور پر سب سے سادہ منظرنامے سے شروع ہوتا ہے — ایک بنیادی HTML صفحے سے متن نکالنا۔ یہ باب آپ کو ان بنیادی تصورات سے روشناس کراتا ہے:

- ویب صفحات حاصل کرنے کے لیے HTTP requests بھیجنا
- HTML content کو parser میں load کرنا
- CSS selectors کے ذریعے بنیادی DOM selection

اگرچہ مثال بظاہر معمولی لگ سکتی ہے (آخرکار یہ صرف ایک "hello world" ہی ہے!)، لیکن یہی آنے والی ہر چیز کی بنیاد رکھتی ہے۔

```html
<!-- Example HTML structure -->
<div class="content">
  <p>Some text we want to extract</p>
</div>
```

یہ اس کام کی ایک جھلک ہے جس پر ہم کام کر رہے ہیں:

```typescript
// Basic concepts (not the solution!)
import * as cheerio from 'cheerio';

// Loading HTML content
const $ = cheerio.load(htmlContent);

// Using CSS selectors
const text = $('p').text();  // Selects all <p> tags
const specific = $('.content p').text();  // More specific selection
```

## باب 2: منظم data

چیزیں مزید دلچسپ ہو جاتی ہیں جب ہم ایک فرضی e-commerce product page میں اترتے ہیں۔ یہاں ہمیں ایک جیسے ڈھانچوں والے متعدد elements کا سامنا ہوتا ہے:

```html
<!-- Example product structure (simplified) -->
<div class="product">
  <h2>Product Name</h2>
  <span class="price">$99.99</span>
  <div class="specs">
    <ul>
      <li>Size: M</li>
      <li>Color: Blue</li>
    </ul>
  </div>
</div>
```

اس طرح کے منظم data کے ساتھ کام کرتے وقت، آپ کو ان باتوں پر غور کرنا چاہیے:

```typescript
// Conceptual approach (not the solution!)
$('.product').each((index, element) => {
  // For each product, we might want to:
  // 1. Extract the basic info
  const name = $(element).find('h2').text();

  // 2. Parse nested data
  const specs = $(element).find('.specs li');

  // 3. Structure the output
  const data = {
    name,
    specs: specs.map(/* ... */),
  };
});
```

پیشہ ورانہ مشورہ: کوئی بھی code لکھنے سے پہلے HTML ساخت کا بغور تجزیہ کرنے کے لیے وقت نکالیں۔ دیکھیں کہ data کس طرح منظم ہے اور اس میں کیا patterns ہیں — کیا class names یکساں ہیں؟ parent اور child elements کے درمیان کیا تعلق ہے؟


## باب 3: AI کی مدد سے اسکریپنگ

اب معاملہ واقعی دلچسپ ہو جاتا ہے! پچھلے challenges نے ہمیں روایتی scraping techniques سکھائی تھیں، لیکن باب 3 ایک جدید طریقہ متعارف کراتا ہے: AI-assisted web scraping۔ یہاں ہمیں ایک ڈراؤنے منظرنامے کا سامنا ہے — غیر یکساں HTML structures، مبہم class names، اور مختلف frameworks کے patterns سب ایک ساتھ ملے ہوئے ہیں۔

آئیے دیکھتے ہیں کہ یہ challenge خاص کیوں ہے:

```html
<!-- Traditional product structure -->
<div data-testid="product-container-1" class="_3xj_item">
  <h2 data-qa="name">Red Sneakers</h2>
  <span data-price-current="5999">$59.99</span>
</div>

<!-- React-style component -->
<div class="ProductCard-root-1a2b3c">
  <div class="ProductCard-title-4d5e6f">Pink Walking Shoes</div>
  <div class="ProductCard-pricing-7g8h9i">$84.99</div>
</div>

<!-- Vue-style template -->
<div data-v-abcdef class="product">
  <h2 data-v-abcdef>Navy Boat Shoes</h2>
  <span data-v-abcdef>$79.99</span>
</div>
```

روایتی scraping approaches کو یہاں مشکل پیش آئے گی کیونکہ:
- class names بے ترتیب یا framework-specific ہیں
- data structures products کے درمیان مختلف ہیں
- مختلف frameworks مختلف patterns استعمال کرتے ہیں
- markup میں معنوی مفہوم کھو جاتا ہے

یہ وہ مقام ہے جہاں AI مدد کو آتا ہے۔ نازک selectors لکھنے کے بجائے، ہم فطری زبان میں بتا سکتے ہیں کہ ہمیں کیا چاہیے اور pattern matching AI پر چھوڑ سکتے ہیں۔ اس باب کے اہم تصورات میں شامل ہیں:

- web scraping کے لیے prompt engineering
- semantic meaning سمجھنے کے لیے AI کا استعمال
- غیر یکساں data structures کو سنبھالنا
- framework-specific markup سے نمٹنا
- مختلف patterns میں data کی یکسانیت برقرار رکھنا

اگرچہ AI کوئی جادو نہیں، لیکن یہ ایسے کاموں میں بہترین ہے جن میں pattern recognition اور مطابقت پیدا کرنا درکار ہو۔ یہی وجہ ہے کہ جدید web applications کی scraping میں یہ خاص طور پر مفید ہے، جہاں یکساں markup patterns کی ضمانت نہیں دی جا سکتی۔

### AI کے استعمال کے بارے میں ایک نوٹ

یاد رکھیں کہ AI assistance کا مطلب مکمل طور پر خودکار solutions نہیں ہوتا۔ بہترین نتائج ان چیزوں کے امتزاج سے حاصل ہوتے ہیں:
- مسئلے کی واضح تعریف
- اچھی ساخت والے prompts
- data validation
- انسانی نگرانی

آپ کا challenge ایسے prompts تیار کرنا ہوگا جو AI کو اس چیز کی structure اور intent دونوں سمجھنے میں مدد دیں جسے آپ extract کرنا چاہتے ہیں۔

کیا آپ روایتی web scraping کے علم کو جدید AI capabilities کے ساتھ جوڑنے کے لیے تیار ہیں؟ آئیے معلوم کریں کہ AI کس طرح سب سے زیادہ بے ترتیب HTML سے بھی نمٹنے میں مدد دے سکتا ہے!

## اشارے

1. مختلف CSS selectors کے ساتھ تجربہ کریں:
```typescript
// Different ways to select elements
$('.class')           // By class
$('#id')             // By ID
$('div > p')         // Direct children
$('div p')           // All descendants
$('[data-type="x"]') // By attribute
```

2. output format میں تبدیلی کرنے کی کوشش کریں
3. error handling اور edge cases کے بارے میں سوچیں
4. غور کریں کہ بڑی datasets کے ساتھ آپ کا solution کس طرح scale کر سکتا ہے

شروع کرنے کے لیے درکار تمام code project repository میں موجود ہے۔ اسے clone کریں، اپنا environment set up کریں، اور scraping شروع کریں!

```sh
git clone https://github.com/jonaylor89/housefly.git
cd housefly
npm install
```

chapter servers کو locally چلائیں — ہر chapter اپنی الگ port (3001–3011) پر چلتا ہے:

```sh
turbo dev
```

اس کے بعد `exercises/chapter-NN/starter/src/index.ts` میں اپنا scraper edit کریں اور اسے validate کریں:

```sh
npm run validate -- <chapter>
```

اشارے چاہیے؟ مرحلہ وار رہنمائی کے لیے `npm run hint -- <chapter>` چلائیں۔ ہر challenge کا source HTML `apps/chapter{n}/` directory میں دستیاب ہے، اور reference solutions `exercises/chapter-NN/solution/src/` میں موجود ہیں۔ ساخت کا مطالعہ کریں، اپنا طریقۂ کار طے کریں، اور یاد رکھیں — ہر ماہر کبھی نوآموز تھا۔

اپنی requests کو ذمہ داری کے ساتھ handle کرنا یاد رکھیں:
```typescript
// Basic error handling example
async function fetchPage(url: string) {
  try {
    const response = await fetch(url);
    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }
    return await response.text();
  } catch (error) {
    console.error('Failed to fetch page:', error);
    throw error;
  }
}
```
