आधुनिक web applications बहुत कम ही पूरा HTML सीधे परोसती हैं — इसके बजाय, सामग्री JavaScript के माध्यम से गतिशील रूप से लोड और रेंडर की जाती है। इससे web scraping में कुछ विशिष्ट चुनौतियाँ सामने आती हैं, जिनका समाधान हम इन दो अध्यायों में करेंगे।

## Chapter 4: गतिशील News Feed

हमारी पहली चुनौती एक ऐसे news feed को scrape करने की है जहाँ लेख JavaScript के माध्यम से गतिशील रूप से लोड होते हैं। इससे कई महत्वपूर्ण अवधारणाएँ सामने आती हैं:

- Playwright के साथ browser automation
- गतिशील सामग्री के लोड होने की प्रतीक्षा करना
- JavaScript-रेंडर्ड DOM elements को संभालना

पृष्ठ की संरचना कुछ इस तरह दिखती है:

```html
<div class="news-feed">
  <article class="news-item">
    <h2>Breaking News Title</h2>
    <p>Article content...</p>
    <div class="meta">
      <span>By Author Name</span>
      <time datetime="2024-03-08T12:00:00Z">March 8, 2024</time>
    </div>
  </article>
  <!-- More articles load dynamically -->
</div>
```
स्थिर HTML scraping की तुलना में मुख्य अंतर:

```typescript
// Instead of cheerio.load(), we use Playwright
const browser = await chromium.launch();
const page = await browser.newPage();

// Wait for content to render
await page.waitForSelector('.news-item');

// Extract data from the live DOM using page.$$eval()
// This runs the callback function in the browser context
// to evaluate all elements matching the selector at once
const items = await page.$$eval('.news-item', elements => {
  // Works like Array.map() on matching elements
  // Returns serializable JavaScript objects
  // Perfect for extracting data from multiple elements
});
```

## Chapter 5: Infinite Scroll Gallery

गतिशील सामग्री की अपनी समझ को आगे बढ़ाते हुए, अब हम एक और अधिक जटिल परिदृश्य से निपटते हैं — infinite scroll वाली एक photo gallery। इससे ये बातें सामने आती हैं:

- lazy-loaded सामग्री को संभालना
- scroll events का पता लगाना और उन्हें ट्रिगर करना
- async loading states का प्रबंधन करना
- जटिल UI patterns से डेटा निकालना

यहाँ चुनौती यह है कि जैसे-जैसे उपयोगकर्ता scroll करता है, सामग्री क्रमिक रूप से लोड होती जाती है:

```html
<div class="photo-gallery">
  <div class="photo-card">
    <img src="..." alt="Photo title" />
    <h2>Photo Title</h2>
    <p>By Photographer Name</p>
    <div class="flex">
      <span>❤️ 42</span>
    </div>
  </div>
  <!-- More photos load on scroll -->
</div>
```

infinite scroll को संभालने के लिए मुख्य अवधारणाएँ:

```typescript
// Scroll to bottom until no new content loads
let previousHeight;
while (true) {
  previousHeight = await page.evaluate('document.body.scrollHeight');
  await page.evaluate('window.scrollTo(0, document.body.scrollHeight)');
  await page.waitForTimeout(1500); // Wait for content

  const newHeight = await page.evaluate('document.body.scrollHeight');
  if (newHeight === previousHeight) {
    break; // No more content to load
  }
}
```

### महत्वपूर्ण बातें

JavaScript-रेंडर्ड सामग्री के साथ काम करते समय:

1. **Performance**: गतिशील सामग्री scraping, स्थिर HTML की तुलना में धीमी होती है
2. **Resource Management**: Browser automation अधिक system resources का उपयोग करता है
3. **Stability**: loading states और network conditions को संभालना ज़रूरी होता है
4. **Rate Limiting**: actions के बीच delays लागू करने पर विचार करें

### सर्वोत्तम तरीके

1. उपयुक्त wait strategies का उपयोग करें:
```typescript
// Wait for specific elements
await page.waitForSelector('.selector');

// Wait for network idle
await page.waitForLoadState('networkidle');

// Custom wait conditions
await page.waitForFunction(() => {
  // Custom JavaScript condition
});
```

2. मज़बूत error handling लागू करें:
```typescript
try {
  await page.goto(url);
  // ... scraping logic
} catch (error) {
  console.error('Scraping failed:', error);
} finally {
  await browser.close(); // Always clean up
}
```

3. विश्वसनीयता के लिए retry mechanisms लागू करने पर विचार करें
4. बड़े datasets के साथ काम करते समय memory usage पर नज़र रखें
5. निकाले गए डेटा की एकरूपता के लिए उसका सत्यापन करें
