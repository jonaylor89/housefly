Web scraping, veri bilimcileri ve geliştiriciler için vazgeçilmez bir beceri hâline geldi; buna karşılık web sitesi sahipleri de savunmalarını geliştirdi. Bu bölüm, web scraping savunmalarıyla süren kedi-fare oyununu ve bunların arasında nasıl etkili şekilde yol alınacağını inceliyor.

## Bölüm 11: Düşman Hattının Gerisinde

Bu bölümde, verilerine kolayca erişilmesini istemeyen simüle edilmiş bir kripto para borsası platformu olan "CryptoDefend Exchange" ile uğraşacaksınız. Birçok finans sitesinde olduğu gibi, CryptoDefend da fiyat verilerinin, işlem hacimlerinin ve piyasa trendlerinin otomatik olarak toplanmasını önlemek için çeşitli savunma önlemleri uygular.

Karşılaşacağınız görev, bu savunmaları kontrollü bir ortamda simüle ederek şunları yapmanızı sağlar:

- Yüksek değerli hedeflerde kullanılan yaygın anti-scraping mekanizmalarını anlamak
- Başarılı veri çıkarımı için pratik stratejiler geliştirmek
- Israr ile teknik zorluklar arasında denge kurmak

## Gerçek Dünyada Çok Katmanlı Savunmalar

Günümüzde anti-scraping cephaneliği birkaç gelişmiş tekniği içeriyor:

### Rate Limiting ve IP Engelleme

En temel savunma hâlâ istek sıklığını izlemek ve eşikleri aşan IP’leri engellemek:

```javascript
// Simplified rate limiting concept
const requestCounts = {};

app.use((req, res, next) => {
  const ip = req.ip;
  requestCounts[ip] = (requestCounts[ip] || 0) + 1;
  
  if (requestCounts[ip] > THRESHOLD) {
    return res.status(429).send('Too Many Requests');
  }
  next();
});
```

Rate limiting ile başa çıkmak için scraper'ınızın şunları yapması gerekir:

- İstekler arasına gecikmeler koymak
- robots.txt yönergelerine uymak
- Büyük ölçekli scraping yaparken IP rotasyonu kullanmayı değerlendirmek

### CAPTCHA’lar ve Etkileşimli Doğrulamalar

CAPTCHA’lar, insanlar için kolay ama botlar için zor görevler sunar. reCAPTCHA v3 gibi modern CAPTCHA’lar hatta arka planda görünmez şekilde çalışarak kullanıcı davranışını analiz eder:

```html
<!-- Example CAPTCHA implementation -->
<form>
  <div class="g-recaptcha" data-sitekey="your-site-key"></div>
  <button type="submit">Submit</button>
</form>
```

CAPTCHA’ların etrafından dolaşmak şunları içerebilir:

- CAPTCHA çözme servisleri kullanmak (ancak etik değerlendirmeler geçerlidir)
- İnsan benzeri davranışı simüle etmek için browser automation’dan yararlanmak
- Bazı içeriklerin erişilemez kalabileceğini kabul etmek

### Davranış Analizi ve Fingerprinting

Gelişmiş savunmalar, botları tespit etmek için fare hareketlerini, kaydırma örüntülerini ve cihaz özelliklerini takip eder:

```javascript
// Simplified fingerprinting concept
function collectFingerprint() {
  return {
    userAgent: navigator.userAgent,
    screenResolution: `${screen.width}x${screen.height}`,
    timezone: Intl.DateTimeFormat().resolvedOptions().timeZone,
    language: navigator.language,
    // Many more signals in production systems
  };
}
```

Bu tekniklere karşı koymak şunları gerektirir:

- İnsan benzeri davranışı simüle edebilen headless browser’lar
- Etkileşim örüntülerini rastgeleleştirmek
- Cookie’leri ve oturum verilerini tutarlı biçimde yönetmek

### Dinamik İçerik ve HTML Gizleme

Birçok site içeriği JavaScript ile render eder ya da öğe ID’lerini ve class adlarını rastgeleleştirir:

```html
<!-- Yesterday's HTML -->
<div class="product-price">$99.99</div>

<!-- Today's HTML after obfuscation -->
<div class="_a7b92f3e">$99.99</div>
```

Bu da scraper'ınızın şunları yapmasını gerektirir:

- Playwright veya Puppeteer gibi tam browser ortamları kullanmak
- Tam seçiciler yerine içerik örüntülerine odaklanmak
- Daha dayanıklı parsing stratejileri uygulamak

## Etik ve Hukuki Hususlar

Bu bölüm savunmalar arasında yol almayı sağlayan teknikleri tanıtsa da şunu unutmamak önemlidir:

- Aşırı scraping, web sitesi performansına zarar verebilir
- Hizmet Şartları çoğu zaman scraping’i açıkça yasaklar
- Bazı yargı bölgelerinde yetkisiz erişime ilişkin yasalar bulunur

Eğitim amaçlı olarak şunları öneriyoruz:

- Production siteleri scrape etmeden önce robots.txt dosyasını kontrol etmek
- İstekler arasına makul gecikmeler koymak
- Verimliliğin önemli olduğu durumlarda API seçeneklerini değerlendirmek
- Uygun olduğunda tanımlanabilir bir user agent kullanmak

## Göreve Yaklaşım

11. Bölümdeki CryptoDefend borsamız, finansal veri toplarken karşılaşabileceğiniz gerçekçi zorluklar sunuyor. Şunlar arasında yolunuzu bulmanız gerekecek:

- Fiyat API endpoint’lerinde rate limiting
- İşlem verilerine erişmek için basit doğrulama bulmacaları
- Yalnızca JavaScript ile render edilen piyasa grafikleri
- Ziyaretler arasında değişen rastgeleleştirilmiş seçiciler

Amaç, bu mekanizmaları anlamak ve veri toplama araç setiniz için pratik teknikler geliştirmektir.

```typescript
// Example of polite scraping with delays
async function politeScraper(urls: string[]) {
  for (const url of urls) {
    // Check robots.txt first
    if (await isAllowedByRobotsTxt(url)) {
      const content = await fetchWithDelay(url, 2000); // 2-second delay
      // Process content...
    }
  }
}
```
