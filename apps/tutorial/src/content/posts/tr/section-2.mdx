Modern web uygulamaları artık nadiren tam HTML sunuyor; bunun yerine içerik JavaScript üzerinden dinamik olarak yüklenip render ediliyor. Bu da web scraping için kendine özgü zorluklar ortaya çıkarıyor ve bunları bu iki bölümde ele alacağız.

## Bölüm 4: Dinamik Haber Akışı

İlk görevimiz, makalelerin JavaScript aracılığıyla dinamik olarak yüklendiği bir haber akışını scrape etmek. Bu, birkaç önemli kavramı beraberinde getiriyor:

- Playwright ile tarayıcı otomasyonu
- Dinamik içeriğin yüklenmesini bekleme
- JavaScript ile render edilen DOM öğelerini ele alma

Sayfanın yapısı kabaca şöyle görünüyor:

```html
<div class="news-feed">
  <article class="news-item">
    <h2>Breaking News Title</h2>
    <p>Article content...</p>
    <div class="meta">
      <span>By Author Name</span>
      <time datetime="2024-03-08T12:00:00Z">March 8, 2024</time>
    </div>
  </article>
  <!-- More articles load dynamically -->
</div>
```
Statik HTML scraping’e göre temel farklar şunlar:

```typescript
// Instead of cheerio.load(), we use Playwright
const browser = await chromium.launch();
const page = await browser.newPage();

// Wait for content to render
await page.waitForSelector('.news-item');

// Extract data from the live DOM using page.$$eval()
// This runs the callback function in the browser context
// to evaluate all elements matching the selector at once
const items = await page.$$eval('.news-item', elements => {
  // Works like Array.map() on matching elements
  // Returns serializable JavaScript objects
  // Perfect for extracting data from multiple elements
});
```

## Bölüm 5: Infinite Scroll Galerisi

Dinamik içerik konusundaki bilgilerimizin üzerine inşa ederek, daha da karmaşık bir senaryoyu ele alıyoruz: infinite scroll kullanan bir fotoğraf galerisi. Bu bölümde şunlarla tanışacağız:

- Lazy-loaded içeriği ele alma
- Scroll event’lerini algılama ve tetikleme
- Async yükleme durumlarını yönetme
- Karmaşık UI kalıplarından veri çıkarma

Buradaki zorluk, kullanıcının scroll yaptıkça içeriğin aşamalı olarak yüklenmesi:

```html
<div class="photo-gallery">
  <div class="photo-card">
    <img src="..." alt="Photo title" />
    <h2>Photo Title</h2>
    <p>By Photographer Name</p>
    <div class="flex">
      <span>❤️ 42</span>
    </div>
  </div>
  <!-- More photos load on scroll -->
</div>
```

Infinite scroll’u ele almak için temel kavramlar:

```typescript
// Scroll to bottom until no new content loads
let previousHeight;
while (true) {
  previousHeight = await page.evaluate('document.body.scrollHeight');
  await page.evaluate('window.scrollTo(0, document.body.scrollHeight)');
  await page.waitForTimeout(1500); // Wait for content

  const newHeight = await page.evaluate('document.body.scrollHeight');
  if (newHeight === previousHeight) {
    break; // No more content to load
  }
}
```

### Önemli Noktalar

JavaScript ile render edilen içerikle çalışırken:

1. **Performans**: Dinamik içerik scraping’i, statik HTML’ye göre daha yavaştır
2. **Kaynak Yönetimi**: Tarayıcı otomasyonu daha fazla sistem kaynağı kullanır
3. **Kararlılık**: Yükleme durumlarını ve ağ koşullarını ele almanız gerekir
4. **Rate Limiting**: Aksiyonlar arasına gecikme eklemeyi değerlendirin

### En İyi Uygulamalar

1. Uygun bekleme stratejileri kullanın:
```typescript
// Wait for specific elements
await page.waitForSelector('.selector');

// Wait for network idle
await page.waitForLoadState('networkidle');

// Custom wait conditions
await page.waitForFunction(() => {
  // Custom JavaScript condition
});
```

2. Sağlam error handling uygulayın:
```typescript
try {
  await page.goto(url);
  // ... scraping logic
} catch (error) {
  console.error('Scraping failed:', error);
} finally {
  await browser.close(); // Always clean up
}
```

3. Güvenilirlik için retry mekanizmaları eklemeyi değerlendirin
4. Büyük veri kümeleriyle çalışırken bellek kullanımını izleyin
5. Tutarlılık için çıkarılan verileri doğrulayın
